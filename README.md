# Let's Eat — Restaurant API

Backend REST API developed for the Let's Eat restaurant application.

## 🚀 Running the project

### 1. Start the database

Use Docker Compose to start the database:

```bash
docker compose up
```
### 2. Start the server

The application server runs on:

http://localhost:8010
### 3. Swagger UI

API documentation is available through Swagger UI:

http://localhost:8010/swagger-ui.html
## 🛠️ Technologies
* Java
* Spring
* REST API
* Maven
* Docker
* Docker Compose
* Swagger

## 📌 Project

The project was developed as a backend component of the Let's Eat application.
